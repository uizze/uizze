# Contributing

Bug reports, clearer rubric wording, and accessibility improvements are
welcome. A benchmark change must remain reproducible and must not silently
change an existing task fingerprint.

1. Fork the repository and create a focused branch.
2. Make the smallest relevant change.
3. Run `npm test` and `npm run verify`.
4. In the pull request, explain whether any task prompt, starter file, or rubric
   changed. A changed fingerprint requires a new benchmark version.

Do not submit fabricated results, generated testimonial copy, tracking links,
credentials, or proprietary screenshots.
