# Results

No candidate results are bundled with the benchmark. That keeps version 1.0.0
from implying comparisons that have not been run.

To publish a result, include a completed submission JSON and link to inspectable
implementation evidence. Run `npm run score -- result.json` before publishing.

Open a [benchmark-result intake](https://github.com/uizze/uizze/issues/new) when the evidence is ready. A maintainer verifies the task fingerprint, score calculation, and public evidence before any result is published. This is not a leaderboard or an endorsement.
