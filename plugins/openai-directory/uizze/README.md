# UIZZE for Codex

This package contains the free UIZZE `anti-ui-slop` skill. Install it from the repository marketplace:

```bash
codex plugin marketplace add uizze/uizze
```

The skill works locally without an account. The optional authenticated UIZZE MCP exposes only `find_ui_references` and `find_ui_materials`. See the [main repository](https://github.com/uizze/uizze) for behavior, privacy, and verification details.
