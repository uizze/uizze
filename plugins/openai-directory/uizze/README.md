# UIZZE for Codex

This package contains the UIZZE `anti-ui-slop` skill and the optional public MCP preview. Install it from the repository marketplace:

```bash
codex plugin marketplace add uizze/uizze
```

The skill works locally without an account. See the [main repository](https://github.com/uizze/uizze) for behavior, privacy, and verification details.
